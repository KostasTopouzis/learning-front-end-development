CSS Layout Algorithms

A property is an input. The algorithm decides what it means.

Which algorithm am I in?

AlgorithmTriggered bySignature behaviour
FlowDefault. Parent is display: block / inlineBlock elements stack vertically; inline elements flow like text. Vertical margins collapse. width/height are ignored on inline elements. z-index needs position.
FlexboxParent display: flex / inline-flexOne axis. width/height feed flex-basis (a suggestion). Items shrink by default (flex-shrink: 1). No margin collapse. z-index works without position.
GridParent display: grid / inline-gridTwo axes; items sit in tracks. No margin collapse. Items can overlap in the same cell. z-index works without position.
PositionedThe element's own position: absolute / fixedTaken out of its parent's algorithm (an absolute child of a flex container is not a flex item). Offsets are measured from the containing block, which is the nearest positioned ancestor.

Also exist: table, multi-column, float. display: flex = block on the outside, Flexbox for its children.

Debugging checklist

  1. Is the declaration applied? In DevTools, a crossed-out declaration means a specificity or cascade problem.
  2. What is the parent's computed display? Look for flex/grid badges in the Elements panel.
  3. What is the element's own position?
  4. How does that algorithm use the property? Look it up for that algorithm specifically.

Known gotchas

Gap under an image

/* Cause: in Flow, img is inline and sits on the text baseline */
img { display: block; }          /* fix A: change its own display */
.frame { display: flex; }        /* fix B: put it in another algorithm */

Margins “disappear” between blocks

/* Flow collapses adjacent vertical margins: max(24, 16) = 24px */
/* In flex/grid they don't collapse. Prefer gap: */
.stack { display: flex; flex-direction: column; gap: 1rem; }

Fixed width ignored inside a flex row

.item { width: 400px; flex-shrink: 0; }   /* opt out of shrinking */

Width on a span does nothing

span { display: inline-block; width: 200px; }
