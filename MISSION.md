# Mission: Advanced Frontend Development

## Why
Land a first job as a **junior frontend developer** (TypeScript / React / Next.js). The route is four frontend-focused portfolio pieces, finished by the end of the academic year (**June 2027**), that I can build, defend and explain in depth in a technical interview.

## Success looks like
- **P1 — Responsive, image-rich marketing site** (Dec 2026 to mid-Jan 2027). Built on a solid CSS layout mental model, with fluid type, container queries, responsive images (`srcset`/`sizes`, `next/image`) and modern gradients/effects. Benchmark: correct from 320px to 1920px, no layout shift, Lighthouse ≥ 95 for Performance and Accessibility.
- **P2 — Design system + starter template** (mid-Jan to early Mar). Built from design tokens, with accessible primitives, dark mode, Storybook, Vitest + Testing Library, Playwright, and CI (lint → typecheck → test → deploy). Benchmark: P3 and P4 start from this template, not from scratch.
- **P3 — Data-rich product app** (Mar to mid-Apr). Benchmark areas: server vs client components, URL and server state, forms and validation, optimistic UI, loading/error states, a real backend (Supabase/Prisma), and E2E tests. Benchmark: a profiled, tested, accessible app with a written architecture decision log.
- **P4 — Interactive / animated showcase** (mid-Apr to June). Benchmark areas: Motion, scroll-driven animations, View Transitions, and SVG effects that respect `prefers-reduced-motion`. Benchmark: smooth 60fps with no jank in a DevTools Performance trace.
- Advanced Tailwind CSS (v4) fluency: theme variables and design tokens, custom utilities/variants, and knowing when to drop to custom CSS, CSS variables or modules, and why.
- For every piece: a 2-minute spoken walkthrough of the hardest decision and its trade-offs.

## Constraints
- 3–4 hours per week.
- Quiz-style lessons are welcome, but the **emphasis is on building the four pieces**. Lessons exist to unblock the next portfolio step.
- Reusable templates and starting models are wanted, both for speed and for study.
- Stack for all pieces: TypeScript, React, Next.js, **Tailwind CSS**, plus custom CSS (variables, modules) where needed.
- Already in place: Vercel and Azure deploys, Azure Flexible Server / Supabase / Prisma, and CI/CD on three full-stack projects.

## Out of scope
- Backend and DevOps depth beyond what a portfolio piece needs (already practised elsewhere).
- Other frameworks (Vue, Svelte, Angular) and native mobile.
