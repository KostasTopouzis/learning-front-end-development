# Tailwind is the primary styling tool, with a goal of advanced fluency

The user works with Tailwind CSS a lot. All four portfolio pieces will use it, with custom CSS (variables, modules) where needed. Getting more advanced in Tailwind is an explicit goal (added to [[MISSION.md]] on 2026-11-23).

**Implications**: always teach the underlying CSS first, then the Tailwind mapping, so Tailwind never becomes a black box. Expect blind spots where Tailwind defaults (Preflight) hide raw CSS behaviour; Lesson 0001 already flags the image-gap case. Tailwind v4 theming (`@theme`) is the natural bridge into P2 design tokens.
