# Starting point: practical full-stack, fragile CSS model, untested

The user self-reports as "almost intermediate." They have hands-on React/Next.js basics and three deployed (incomplete) full-stack projects. They have used Vercel and Azure deploys, Azure Flexible Server, Supabase, Prisma and CI/CD pipelines. They use CSS flex/grid but say "something is missing from the whole picture." Responsive images and testing are explicit weak spots. Advanced React is not yet touched.

**Evidence**: self-report at the start of the first session (2026-11-23). Not yet verified by exercises.

**Implications**: skip deploy, database and CI basics. Start with the CSS mental model (layout algorithms) before responsive images, because image bugs are often layout bugs. Introduce testing in P2 with the testing-trophy framing, not as isolated unit tests.
